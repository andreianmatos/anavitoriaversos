# Miniaturas na raiz do arquivo

Só para ficheiros **directamente** em `imagens/arquivo/` (sem subpasta), por exemplo `natureza mae.png` → `thumbs/natureza mae.png`.

Obras em `imagens/arquivo/<slug>/` usam **`<slug>/thumbs/`** (ou `consequencias/thumbs/`). Não copies essas miniaturas para aqui — o site e o `generate-thumbs.sh` não precisam de duplicados.
